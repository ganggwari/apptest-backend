휴대폰 설치 방법

  1. 위에서 원하는 앱을 엽니다.
  2. 안드로이드: Chrome 메뉴에서 ‘앱 설치’ 또는 ‘홈 화면에 추가’를 선택합니다.
  3. 아이폰: Safari의 공유 메뉴에서 ‘홈 화면에 추가’를 선택합니다.

인터넷에 연결된 HTTPS 주소에서 이용해 주세요. ZIP 파일을 휴대폰에서 열어 설치하는 방식은 지원하지 않습니다.

실시간 지도·날씨·로그인은 인터넷과 서버 연결이 필요합니다. 미리보기의 상태·수치는 구성 예시입니다.
